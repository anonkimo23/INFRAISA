# 🌐 Enterprise Multi-Variable Routing & Sink Tree Simulator

Simulador de enrutamiento adaptativo de alta fidelidad basado en el **Principio de Optimalidad**, función de costos multicriterio ($α, β, γ$) y construcción de árboles sumidero (*Sink Trees*).

## 🚀 Características Principales
- **Gestión Dinámica de Red:** Permite añadir routers y configurar/eliminar enlaces personalizados en tiempo real.
- **Algoritmo de Dijkstra & Sink Tree:** Calcula automáticamente las rutas óptimas hacia cualquier nodo sumidero elegido.
- **Función Multicriterio:** Ponderación dinámica de Retardo, Capacidad y Disponibilidad.
- **Telemetría y Control de Fallos:** Panel analítico con métricas clave y simulación de caídas de enlaces.
